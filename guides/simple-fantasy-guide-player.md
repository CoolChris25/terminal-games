# Simple-fantasy (placeholder name)
**This game is a simple project, the objective is to get as much gold as possible and become the best.**

## Controls
These are all the controls for the game as of version 1.0.0
### Intermission Menu
**Option 1:** ***"Explore / Battle Next Monster":***
start the next battle with your selected region & difficulty

**Option 2:** ***"Open Backpack / Equip Gear":*** Check the contents of your inventory to equip or use items.

**Option 3:** ***"Visit Shop":*** Visit a shop to spend gold to buy random items.

**Option 4:** ***"View Character Stats":*** See all stats, like HP and equipped items.

**Option 5:** ***Change Location / Difficulty":*** change what region and difficulty you would like to start the next battle with.
